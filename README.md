# skohscripts.github.io

Site CV de Corentin Michel : **<https://skohscripts.github.io/>** (FR) et
[`/en/`](https://skohscripts.github.io/en/) (EN).

Ce dépôt public ne contient que le **site déjà construit**, sur la branche
`gh_pages`, servie par GitHub Pages. Les sources (contenu, CV LaTeX, gabarits,
scripts) sont dans un dépôt privé, dont la CI régénère et republie le site à
chaque modification et chaque jour (métriques à jour).

Réglage : *Settings → Pages → Source* = **Deploy from a branch**, `gh_pages`, `/ (root)`.
Ne pas modifier `gh_pages` à la main : chaque publication la remplace.
